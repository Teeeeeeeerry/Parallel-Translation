# 图标与品牌标识

标识是「A / 文」：拉丁字母在上、汉字在下，对应产品的「原文在上、译文在下」。
A 用纸感米白、文用黄铜金，两个颜色都取自 `src/styles/tokens.css` ——
颜色本身区分了原文与译文，因此不需要额外的分隔线。

## 唯一真相在 src/ui/logo.ts

字形是几何笔画路径，不是 `<text>`。图标一旦依赖系统字体，换台机器渲染出来的
PNG 就会走形，而这四个 PNG 是要上架的。

四个消费方共用那一份定义，不存在第二套画法：

| 消费方 | 用法 |
|---|---|
| `public/icon/{16,32,48,128}.png` | 本目录的 `generate.ts` 渲染 |
| popup 头部标识 | `entrypoints/popup/main.ts` 注入 `logoMarkSvg(32, { compact: true })` |
| 悬浮球 idle 态 | `src/ui/floating-ball.ts` 的 `IDLE_MARK` |
| 宣传图 | `capture.mjs` 读本目录的 `icon-mark.svg` 注入 |

## 重新生成

```bash
pnpm icon:build
```

产出 `public/icon/` 四个 PNG，以及本目录的 `icon-128.svg`、`icon-mark.svg`
（后者是无底色的纯字形，宣传图用它）。改完字形务必重跑，否则 PNG 与代码里的
标识会各走各的。

## 三档细节层级

尺寸越小笔画越少 —— 不同尺寸给不同细节是图标设计的常规做法，
Chrome 的四个尺寸本就是独立 PNG。

| 层级 | 用于 | 图形 |
|---|---|---|
| `REGULAR` | 128 / 48 | 完整「A / 文」，笔画细、结构舒展 |
| `COMPACT` | 32、popup 头部 | 同样是「A / 文」，字形放大、张开角度加大 |
| `MICRO` | 16、悬浮球 | 只画「A」加一条黄铜金横条 |

两个尺寸上的坑，改参数前值得知道：

- **32 不能靠加粗取清晰度**。笔画一粗，「文」的撇捺就在交叉处粘成一个实心块，
  反而认不出字。清晰度要从张开角度上要，不是从笔画重量上要。
- **16 画不下四笔的汉字**，怎么调都糊，所以退到 `MICRO`。悬浮球虽然有 44px，
  但字形只占 28px，且方形字形放进圆形容器会上下顶边，同样用 `MICRO`。

## 悬浮球只有 idle 态画标识

`loading` / `done` / `error` 仍是 `…` / `✓` / `!` 三个字符。
`done` 态的底色会变成黄铜金，而标识里的「文」正是黄铜金，画上去会直接消失在背景里。
