# 商店截图

Chrome Web Store 要求 1280×800（或 640×400）PNG/JPEG，本项目统一用 **1280×800 PNG**。

截图必须在真实浏览器里加载真实扩展后实拍 —— 无法由构建脚本或测试运行器生成，
因此这一项由人工补齐，本目录先固化规格与命名。

| 文件名 | 内容 | 拍摄步骤 |
|---|---|---|
| `01-bilingual.png` | 对照模式全貌 | 打开一篇 Wikipedia 英文长条目 → 工具栏点「翻译此页」→ 滚动到正文中段截图 |
| `02-translation-only.png` | 仅译文模式 | 同一页面 → popup 里切「仅译文」→ 截同一段落 |
| `03-styles.png` | 6 种样式对比 | 设置页 → 外观分区 → 依次切换预设，把预览区拼成一张对比图 |
| `04-options.png` | 设置页 | 设置页 → 引擎分区（能同时展示优先级拖拽与 BYOK 密钥两块） |
| `05-selection.png` | 划词翻译 | 任意页面 → 选中一段文字 → 右键「翻译所选文本」→ 截译文弹出的瞬间 |

拍摄前的检查：

- 浏览器缩放 100%，窗口宽度足够让正文不折行到异常版式
- 关掉其他扩展的图标，避免工具栏杂乱
- 不要出现真实的 API key、个人书签、账号头像
- 界面语言按目标商店区域设置（简中商店用简中截图）
