后台管理系统

RuoYi 是一个后台管理系统，基于经典技术组合（Spring Boot、Apache Shiro、MyBatis、Thymeleaf）主要目的让开发者注重专注业务，降低技术难度，从而节省人力成本，缩短项目周期，提高软件安全质量。

RuoYi 框架提供 Spring Boot 2.x / 3.x / 4.x 多版本分支的并行维护。如需 Vue 分离版本，请移步 RuoYi-Vue，如需 Cloud 微服务版本，请移步 RuoYi-Cloud。

代码下载：https://gitee.com/y_project/RuoYi/tree/springboot3 、 https://gitee.com/y_project/RuoYi/tree/springboot2

一直想做一款后台管理系统，看了很多优秀的开源项目但是发现没有合适的。于是利用空闲休息时间开始自己写了一套后台系统。如此有了若依。她可以用于所有的 Web 应用程序，如网站管理后台、网站会员中心、CMS、CRM、OA 等等，当然，您也可以对她进行深度定制，以做出更强系统。所有前端后台代码封装过后十分精简易上手，出错概率低。同时支持移动客户端访问。
